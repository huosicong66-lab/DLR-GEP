# One-Day-Ahead AQI Prediction Using DLR-GEP

This repository contains the data, source code, prediction results, and evaluation procedures associated with the DLR-GEP model for one-day-ahead Air Quality Index (AQI) prediction.

## Study Overview

The proposed method combines regularized linear feature enhancement with an improved Gene Expression Programming (GEP) predictor. The linear module is fitted using only the chronological training data and generates contribution features and an auxiliary prediction. These variables are combined with the original historical features and supplied to the improved GEP model to predict the AQI for the following day.

The improved GEP model incorporates multi-elite guidance, dynamic evolutionary pressure control, disturbance suppression, temporally segmented fitness evaluation, validation-based model selection, and median ensemble prediction.

## Dataset

Daily air-quality records for Beijing and Nanning, China, from 1 January 2022 to 31 December 2024 were obtained from the publicly accessible Tianqihoubao historical air-quality database:

https://www.tianqihoubao.com/aqi/

Each city dataset contains the following variables:

- AQI
- PM2.5
- PM10
- SO2
- NO2
- CO
- O3

Only publicly displayed environmental information was used. No restricted content was accessed, and no access-control mechanism was bypassed. The data were used solely for non-commercial academic research.

## Prediction Protocol

For each target day `t + 1`, the input data include only pollutant and AQI observations available from days `t - 6` to `t`. No pollutant concentration or AQI value from the target day is included in the input features.

After data cleaning and historical feature construction, each city contains:

- 685 training samples
- 171 validation samples
- 215 independent testing samples
- 84 original historical input features

All preprocessing parameters and model hyperparameters are determined using only the training and validation periods. The independent test data are used exclusively for final evaluation.

## Models

The repository includes the following prediction models:

- Linear Regression (LR)
- Dynamic Linear Regression (DLR)
- Random Forest (RF)
- Autoregressive Integrated Moving Average (ARIMA)
- Bidirectional Long Short-Term Memory (BiLSTM)
- Gene Expression Programming (GEP)
- Proposed DLR-GEP

## Experimental Scripts

- `01_prepare_data.py`: data cleaning and historical feature construction
- `02_lr_baseline.py`: linear regression baseline
- `03_dlr_baseline.py`: DLR baseline
- `04_rf_baseline.py`: random forest baseline
- `05_gep_baseline.py`: standard GEP baseline
- `06_dlr_gep_nested.py`: proposed DLR-GEP model
- `07_ablation_study.py`: component-wise ablation experiments
- `08_classification_evaluation.py`: AQI category evaluation
- `09_statistical_tests.py`: Diebold-Mariano tests with Holm correction
- `ARIMA_baseline.py`: ARIMA baseline
- `BiLSTM_baseline.py`: BiLSTM baseline

## Reproduction Order

Run the scripts in the following order:

1. `01_prepare_data.py`
2. Baseline scripts
3. `06_dlr_gep_nested.py`
4. `07_ablation_study.py`
5. `08_classification_evaluation.py`
6. `09_statistical_tests.py`

The baseline scripts can be executed after data preparation. The evaluation and statistical-analysis scripts require the prediction files generated by the corresponding models.

## Results

The `results/` directory contains:

- Test-set predictions
- Regression metrics
- AQI category evaluation results
- Ablation-study results
- Diebold-Mariano statistical test results

The main regression metrics are MSE, RMSE, MAE, and MAPE. AQI category performance is evaluated using accuracy, macro-precision, macro-recall, macro-F1, and confusion matrices.
